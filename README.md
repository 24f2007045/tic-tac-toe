# Tic-Tac-Toe Web App

A modern and interactive **Tic-Tac-Toe game** built using **HTML, CSS, and JavaScript** with a beautiful neon UI and smooth gameplay experience.

---

## Live Demo

 https://24f2007045.github.io/tic-tac-toe/

---

##  Features

*  Classic 2-player Tic-Tac-Toe
*  Turn indicator (Player 1 / Player 2)
*  Score tracking system
*  First to 5 wins the match
*  Winner & draw popup
*  Reset board option
*  New game (resets score + board)
*  Modern neon gradient UI
*  Smooth hover & animations

---

##  Tech Stack

* HTML5
* CSS3 (Flexbox + Gradients + Glassmorphism)
* JavaScript (DOM Manipulation & Game Logic)

---

##  Project Structure

```
tic-tac-toe/
│── index.html
│── style.css
│── script.js
```

---

##  How It Works

* Players take turns placing **O** and **X**
* Game checks all winning patterns after each move
* Score updates automatically after each win
* When a player reaches **5 wins**, match ends
* Popup displays winner and option to start new game
